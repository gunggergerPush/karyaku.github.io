Motion

Kategori Motion digunakan untuk menggerakkan sprite di panggung (Stage). Koordinat x mengatur posisi horizontal, sedangkan y mengatur posisi vertikal.

move 10 step

gerak 10 langkah menggerakan sprite 10 langkah ke arah manapun yang dihadapinya

go to random position

pergi ke posisi acak, blok ini memmungkin sprite untuk dipindahkan kemana saja di dalam batas layar

glide 1 sec to random position and to x y

meluncurkan sprite secara halus menuju tujuan dalam waktu tertentu dan Meluncur ke koordinat tertentu.

set x and set y

Set X=Menetapkan posisi horizontal. set Y=menetapkan posisi vertikal.

set rotation style (All round).

Menentukan cara sprite berputar ada pilihan untuk tidak berputar,berputar ke kiri dan berputar ke segala arah.

x position y position direction

Menghasilkan nilai posisi horizontal sprite. Y positionMenghasilkan nilai posisi vertikal sprite. Direction=Menghasilkan nilai arah hadap sprite.

15 clockwise and countercclockwise

clockwise memutar sprite searah jarum jam sedangkan counterclockwise memutar sprite berlawanan arah jarum jam.

go to x and y

memindahkan sprite ke X= menambah angka barisa di garis horizontal sesuai yang di kasi Y= menambah angka barisan di garis vertikal sesuai yang di kasi

point in direction and point torwards (mouse-pointer)

mengatur arah hadap sprite dan mengarahkan sprite ke mouse atau sprite lain

change x and y

X=menambah atau mengurangi posisi horizontal Y=menambah atau mengurangi posisi vertikal

if on edge bounce

membuat sprite memantul ketika menyentuh tepi layar

Looks

Kategori Looks digunakan untuk mengubah penampilan sprite dan latar panggung

say hello! for 2 seconds and say hello.

Menampilkan teks percakapan selama beberapa detik dan sampai diganti atau di hapus

think hmm.. for 2 seconds and think.

menampilakan teks mikir dalam beberapa detik

switch backdrop to backdrop1

Mengganti latar panggung

witch costume to costum 2.

Mengganti kostum sprite

change size by

Memperbesar atau memperkecil ukuran.

change color effect by 25.

Mengubah efek visual, misalnya warna

Clear graphic effects

menghapus semua efek garis.

show and hide

hide menyembunyikan sprite, show menampilkan sprite

Sound

Kategori Sound digunakan untuk menambahkan musik, suara karakter, dan efek suara.

play sound (meow) until done

memutar suara sampai selesai sebelum melanjutkan kode.

stop all sound

menghentikan semua suara

change volume by (-10)

mengurangi atau menambah volume

clear sound effects

menghapus efek suara

change (pitch) effect by (10) and set (pitch) effect to (100)

mengganti pitch mengubah efek suara,misalnya tinggi-rendah nada sedangkan set menentukan nilai efek suara

volume

memperlihatkan nilai volume saat ini.

Events

events menentukan kapan sebuah kumpulan kode mulai dijalankan.

when greenflag clicked

memulai kode ketika bendera hijau di klik

when (space) key pressed

memulai kode ketika tombol keyboard ditekan.

when this sprite clicked

memulai kode ketika sprite diklik

when (loudness) > (10)

menjalakan kode ketika kondisi sensor tertentu terpenuhi.

when i receive (message1)

menjalankan kode ketika menerima pesan siaran

broadcast (message1)

mengirim pesan kepada sprite atau skrip lain.

broadcast (message1) and wait

mengirim pesan dan menunggu skrip penerima menyelesaikan tugasnya

Events Blocks

Penjelasan tentang pemicu program.

Control

Control mengatur urutan pelaksanaan program, pengulangan, kondisi, dan kloning sprite.

wait (1) seconds

menunggu selama waktu tertentu.

repeat (10) and forever

repeat (10) mengulang kode sebanyak jumlah yang ditentukan, forever, mengulang kode terus menerus.

if <> then and if <> then else

if <> then menjalankan kode jika kondisi benar sedangkan if <> then else, memilih satu dari dua tindakan berdasarkan kondisi.

wait unti <>

menunggu sampai kondisi menjadi benar.

repeat unti <>

mengulang sampai kondisi menjadi benar.

stop (all)

menghentikan semua kode, kode pada sprite ini, atau skrip lainnya sesuai pilihan.

when i start as a clone and create clone of (myself)

when i start as a clone itu menjalankan kode ketika clone mulai aktif dan create clone of myself membuat salinan sprite.

delete this clone

menghapus clone yang sedang berjalan

Sensing

Sensing memungkinkan program mengetahui kondisi lingkungan dan menerima masukan pengguna.

touching (mouse-pointer)?.

memeriksa apakah sprite menyentuh objek tertentu

touching (color)?

touching color (color)? memeriksa apakah sprite menyentuh warna tertentu sedangkan color (color) is touching (color)? memeriksa apakah satu warna menyentuh warna lain

distance to (Mouse-pointer)

menghitung jarak ke mouse atau sprite lain.

ask (what's your name?) and wait

mengajukan pertanyaan dan menunggu jawaban.

answer

menampilkan hasil jawaban terakhir pengguna.

key (space) pressed?

memeriksa apakah tombol tertentu sedang ditekan.

mouse down?

memeriksa apakah tombol mouse sedang ditekan.

mouse x and y

mouse x menghasilkan posisi horizontal mouse sedangkan mouse y menghasilkan posisi vertikal mouse.

set drag mode (draggable/not draggable).

menentukan apakah sprite dapat diseret dengan mouse

loudness and timer

loudness mengukur tingkat suara yang terdeteksi mikrofon jika ada dan timer menghasilkan waktu sejak timer dimulai atau diatur ulang.

reset timer

mengatur ulang timer.

([attribute] of [sprite])

mengambil properti sprite atau panggung yang dipilih.

current(year)

memperlihatkan tanggal atau waktu saat ini.

days since 2000

menghasilkan jumlah hari sejak tanggal acuan scratch.

username deskripsi

menghasilkan nama pengguna scratch jika tersedia

Operator

Operators digunakan untuk matematika, membandingkan nilai, menggabungkan teks, dan membuat kondisi logika.

( ) + ( ), ( ) - ( ),( ) * ( ), dan ( ) / ( ).

+ menjumlahkan dua nilai, - mengurangi dua nilai, * mengalikan dua nilai, dan / membagi dua nilai.

pick random (1) to (10).

menghasilkan angka acakdalam rentang tertentu.

( ) > ( ), ( ) < ( ), dan ( ) = ()

> memeriksa apakah nilai kiri lebih besar, < memeriksa apakah nilai kiri lebih kecil, dan = memeriksa apakah kedua nilai sama.

< > and < >, < > or < >, and not < >

< > and < > benar jika kedua kondisi benar sedangkan < > or < > benar jika setidaknya satu kondisi benar, dan not < > membalik nilai benar menjadi salah, atau sebaliknya.

join (apple) (banana), letter (1) of (apple), length of (apple), and (apple) contains (e)?.

join (apple) (banana) artinya menggabungkan dua teks sedangkan letter (1) of (apple) artinya mengambil karakter pada posisi tertentu dan length of (apple) artinya menghitung panjang teks dan terakhir (apple) contains (e)? artinya memeriksa apakah teks mengandung bagian tertentu?.

( ) mod ( ), and round ( )

( ) mod ( ) artinya menghasilkan sisa pembagian dan round ( ) artinya membulatkan angka ke bilangan bulat terdekat.

[abs] of ( ).

menghitung fungsi matematika seperti nilai mutlak, akar, atau fungsi lain yang tersedia pada menu.

Variable

Variabel adalah tempat menyimpan satu nilai, seperti skor, nyawa, nama, atau jumlah koin.

my variable

menampilkan pengguna memiliki berapa variable.

set (score) to (0) and change (score) by (1)

set (score) to (0) artinya mengatur nilai variable sedangkan change (score) by (1) artinya menambah atau mengurangi nilai variable.

show variable (score) and hide variable (score)

show variable (score) artinya menampilkan nilai variable di punggung sedangkan hide variable (score) menyembunyikan tampilan variabel.

My blocks

Memungkinkan kamu membuat blok sendiri untuk mengelompokkan perintah yang sering digunakan.

my blocks

Make a Block: membuat blok baru. Define block: menentukan perintah yang dijalankan oleh blok buatan tersebut. Input/parameter: memungkinkan blok menerima nilai, seperti jumlah langkah atau nama objek
